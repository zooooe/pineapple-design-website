# Big Pineapple Creative

Bilingual static portfolio for 大菠萝创意 / Big Pineapple Creative.

## Netlify deployment

- Production branch: `main`
- Base directory: repository root
- Build command: leave empty
- Publish directory: `dist`
- No package installation, API keys or environment variables required.

Open `dist/index.html` to preview. Language selection uses `?lang=zh` or `?lang=en`.

The contact form uses FormSubmit and requires recipient email activation after the first hosted submission. Email delivery has not yet been verified. Local file previews cannot submit.

This work-in-progress version still includes placeholder projects.
